# ADR 0005 — PDF generation: WeasyPrint with all network access blocked

Status: accepted

Options: WeasyPrint (HTML/CSS → PDF in-process, BSD), headless Chromium
(heavy image, sandbox concerns), ReportLab (imperative layout, slower to build
finance-style documents).

Decision: **WeasyPrint 70** in the worker. A custom URL fetcher refuses every
URL (no `http(s)`, no `file:`); fonts and images are embedded as data URIs from
the application package. Templates are Jinja2 with autoescape on. A test proves
an external URL in the document is not fetched (PHASES §7).
